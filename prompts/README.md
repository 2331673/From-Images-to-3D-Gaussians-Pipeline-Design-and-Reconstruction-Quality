## Technical scope

The prompts cover implementation, environment troubleshooting, experiment orchestration, verification, numerical analysis, and writing. Configurations, commands, checkpoints, and evaluation outputs are the records of the actual experiments.

The sequence refers to the ten primary reconstructions and two available initialization comparisons. Requests to inspect possible mechanisms do not imply additional ablations were performed. Member identities, student identifiers, private paths, and authentication information are excluded. The report and its generation code are submitted separately from this repository.
